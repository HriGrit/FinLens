## Commands

```bash
# All uv commands run from backend/
cd backend
uv sync                                              # install/update all dependencies
uv run pytest                                        # run tests (backend/tests/)
uv run python -m ingestion.run_ingestion             # run offline ingestion pipeline
uvicorn api.main:app --reload                        # start FastAPI dev server

# Infrastructure (from repo root)
docker compose up -d                                 # start Qdrant + Langfuse + Postgres

# Validation / integration tests (run after uv sync; from backend/)
uv run python ../tests/validate_qdrant.py            # M0.4: Qdrant round-trip
uv run python ../tests/validate_llm.py               # M0.5: LiteLLM -> OpenRouter -> Mistral
uv run python ../tests/validate_reranker.py          # M0.6: Cross-encoder ranking
```

## Architecture

FinLens is a financial document RAG pipeline (Python >=3.12), managed with `uv`.

### Pipeline flow

**Offline (ingestion) — `backend/ingestion/`:**
1. **Parse** (`parse.py`) — `doc_to_nodes` converts a DoclingDocument to LlamaIndex `TextNode` objects with 6 required metadata fields: `element_type`, `page_number`, `filename`, `company`, `year`, `doc_type`.
2. **Enrich** (`parse.py`) — `inject_heading_context` prepends section heading to each node and drops heading nodes.
3. **Chunk** (`chunk.py`) — `split_paragraph_nodes` semantically splits paragraph nodes via `SemanticSplitterNodeParser`; non-paragraph nodes (tables, etc.) pass through. Asserts all required metadata fields are present.
4. **Index** (`index.py`) — `build_qdrant_index` embeds and upserts into Qdrant; `build_bm25_index` pickles a BM25Retriever.

**Online (query) — `backend/retrieval/`, `backend/generation/`:**
5. **Hybrid retrieve** (`retrieval/hybrid.py`) — BM25 + Qdrant dense retrieval fused with RRF.
6. **Rerank** (`retrieval/rerank.py`) — cross-encoder (`cross-encoder/ms-marco-MiniLM-L-6-v2`) scores candidates.
7. **Generate** (`generation/generate.py`) — LiteLLM → OpenRouter → Mistral with citation assembly.

**API** — `backend/api/main.py`: FastAPI, POST /chat + GET /health.
**Observability** — `backend/observability/tracing.py`: Langfuse spans.
**Eval** — `eval/ragas_eval.py`: RAGAS scoring against `eval/thresholds.yaml`.

### Key dependencies (`backend/pyproject.toml`)

- `docling` — PDF parsing
- `llama-index` + `llama-index-embeddings-huggingface` — node abstractions, `Alibaba-NLP/gte-modernbert-base` embedding (768-dim)
- `qdrant-client` + `llama-index-vector-stores-qdrant` — vector store
- `llama-index-retrievers-bm25` — sparse retrieval
- `sentence-transformers` — cross-encoder reranking
- `litellm` — LLM abstraction (OpenRouter/Mistral)
- `langfuse` — observability
- `fastapi` + `uvicorn` — API server
- `ragas` + `datasets` — evaluation

### Conventions

- Python PEP 8: `snake_case` functions/variables, `PascalCase` classes, `UPPER_SNAKE_CASE` constants.
- Add type hints to all new/edited functions.
- `ingestion/` is **offline-only** — never imported by `api/` or `retrieval/` at query time.
- Tests live in `backend/tests/test_<feature>.py`; prefer deterministic unit tests over full PDF end-to-end tests.
- Secrets go in `.env` (gitignored); use `python-dotenv` to load them.
